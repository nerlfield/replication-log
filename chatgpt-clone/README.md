# ChatGPT Clone (Frontend)

This is a lightweight ChatGPT-style interface built with:

- React 18 + TypeScript
- Vite bundler
- Radix UI primitives for accessible scrollbars
- Mocked API calls (no backend required)

## Available Scripts

```bash
npm install       # install dependencies
npm run dev       # start development server
npm run build     # build for production
npm run preview   # preview production build
```

## Notes

The API logic is mocked in `src/api/mockApi.ts`. Replace it with real network calls once your backend is ready.
